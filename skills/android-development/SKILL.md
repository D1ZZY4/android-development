  ROM/AOSP/LineageOS from a device tree, building or porting a kernel

  (bootloops, crashes, kernel panics, SELinux denials, service deaths, HAL

  via ADB. Trigger on: device tree, repo sync/manifest, lunch/breakfast,
  mka/mka bacon, defconfig, Image.gz-dtb, boot.img, AnyKernel3, GKI,
  kernelsu, .rc/.te/.mk/.bp files, adb logcat/dmesg/tombstones, ROM or
  kernel build failures, device bootlooping, avc denied, neverallow,
  sepolicy, property_contexts, checkpolicy/checkfc errors, module.prop,
  Magisk modules, KernelSU/KSU-Next modules, Zygisk, or a flashable
  AnyKernel3 ZIP. Also for build-environment setup, BoardConfig.mk/
  Android.bp fixes, kernel diff review. Read REFERENCE.md for exact
  commands before running build/debug commands. Prefer over general
  coding help whenever AOSP, a device tree, kernel source, or Android
  system-modification package is involved.
